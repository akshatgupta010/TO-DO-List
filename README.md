# To-Do List

A simple and interactive To-Do List web application built using HTML, CSS, and JavaScript.

This project is part of learning frontend development and helps practice working with the DOM, JavaScript logic, event handling, and browser local storage.

## Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Save tasks in browser local storage so they remain after refreshing the page

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` — contains the app structure
- `style.css` — styles the user interface
- `script.js` — handles task logic and interactions

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start adding your tasks.

You can also serve it locally if you prefer:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Learning Goals

This project is useful for learning:

- DOM manipulation
- Event listeners
- JavaScript functions
- Arrays and objects
- Local storage
- Dynamic UI updates

## How It Works

- Type a task into the input field and click the Add button.
- Use the checkbox to mark tasks as done or undone.
- Double-click the task text to edit it.
- Click Delete to remove a task.
- Refresh the page and your tasks remain saved in local storage.
